## 問い

オーケストラの団員に「今日は好きな席に座っていいですよ」と言ったらどうなるか。

たぶん、演奏にならない。第一バイオリンは指揮者の左手前に、コントラバスは右奥に。どこに誰が座るかは、好みで決まっているのではない。**音楽が成り立つための配置として、決まっている。**

原典の授受作用も、これに似ている。誰と誰の間でも成り立つものではない。主体と対象という役割があり、中心があり、位置がある。

:::quote 0
授受作用がなされるときの、このような四つの位置の土台を四位基台という
:::

**「位置」という語が効いている。** 誰と誰でもいいのではなく、決まった配置がある。

では、その配置はなぜ決まるのか。神にとっての対象が人間であることは、選んだ結果なのか。それとも、構造から導かれることなのか。取り替えはきくのか、きかないのか。

数学には、二つの側の間の「いちばんぴったりの対応」を、条件から唯一に決まるものとして捉える枠がある。**随伴**だ。好みで選んだ対応と、構造から定まる対応とを見分ける道具になる。

## 主張

**主体と対象の組は、たまたま出会った二者ではない。条件を満たす、ただ一つの対として捉えられうる。**

随伴とは、二つの側を行き来する二つの向きの働きがあり、それが過不足なく噛み合っている状況のことだ。**過不足なく**、が要点になる。これが成り立つ対応は、条件を満たす限り、本質的に一つしかない。

主体と対象が特定の対であることは、好みの問題ではない。この種の「一つに定まる」こととして読める。それが本稿の主張だ。

先に断っておく。本稿は `比喩` として出す。原典の側に、数学の「圏」に当たるものを特定できていない。だから構造的対応とは言えない。**借りているのは、形の輪郭だけだ。**

## 前提

**原典から置くもの。**

第一に、授受作用には位置がある（前掲の引用）。中心・主体・対象・結果という四つの位置が、ひとつの構造をなす。

第二に、喜びは、自分に似た対象から来るとされる。**似ていることが、対象の資格になっている。**

:::quote 1
主体の喜びは、自己の性相と形状に似た対象からくる刺激によって得ら れる
:::

第三に、中心を欠いた二者の関係を、原典は授受作用と呼ばない。中心は飾りではなく、構造の一部だ。

**数学から置くもの。**

随伴を、専門用語を使わずに説明してみたい。いちばん身近な例は、たぶん「切り上げ」だ。

2.3 を整数にしたい。候補はいくらでもある。3 でも 4 でも 100 でもいい。でも「2.3 以上の整数のうち、いちばん小さいもの」と条件をつけた瞬間、答えは 3 に決まる。誰かが 3 を選んだわけではない。**条件が、3 を決めた。**

しかもこの切り上げには、きれいな性質がある。「2.3 を切り上げたものが n 以下である」ことと、「2.3 が n 以下である」ことが、どんな整数 n についてもぴったり一致する。整数の世界で測った関係と、実数の世界で測った関係が、過不足なく重なる。

これが随伴の骨格だ。三点にまとめておく。

一つ目は、**二つの向きがあること**。実数を整数へ送る働きと、整数を実数の中へ戻す働きが対になる。片方だけでは随伴にならない。

二つ目は、**過不足のない対応**。一方の側で測った関係と、もう一方の側で測った関係が、多くも少なくもなく一致する。

三つ目は、**一意性**。この条件を満たす対応は、あるとすれば本質的に一つに決まる。**選ぶのではない。定まるのだ。**

| 圏論 | 原典（本稿の読み） |
|---|---|
| 二つの側 | 主体と対象 |
| 左右の向き | 授ける働きと受ける働き |
| 過不足のない対応 | 授受が閉じて四位基台が成り立つこと |
| 一意性 | 対象が取り替えのきかないものであること |
| 特徴づけの条件 | 中心（心情または目的） |

## 導出

**一。** 授受作用には二つの向きがある。授けることと、受けること。この二つが対になって、ひとつの作用になる。片方だけでは成り立たない。

**二。** 随伴も、二つの向きの対だ。**片方だけでは定義できない**という点で、形が一致する。

**三。** 随伴が特別なのは、二つの向きが過不足なく噛み合うところにある。授受作用も同じだ。授けたものが受け取られ、受け取られたものが返ってくる。**余りが出れば、閉じない。** 原典が四位基台を「土台」と呼び、位置がすべて埋まった状態として描くのは、この閉じ方に近い。

**四。** 随伴は、条件から一つに定まる。ここが本稿の狙いだ。神にとっての対象が人間であることを、好みではなく**構造の帰結**として読む余地が出てくる。2.3 の切り上げが 3 であるのと同じように。

**五。** そして、中心の役割が説明できるようになる。随伴は「何にとって、いちばんぴったりか」を指定しないと決まらない。切り上げで言えば「以上のうち最小」という条件だ。原典の中心（心情または目的）は、この指定に当たる。**中心が変われば、ぴったりの対も変わる。** [[mutual-information]] では中心を条件付けとして読んだ。ここでは、対を決める条件として読んでいる。

**六。** 最後に、非対称が出てくる。随伴には左と右があり、入れ替えられない。切り上げと「整数を実数として見る」働きは、役割が違う。**主体と対象は対等だが、同じではない。** 原典が両者を区別し続けることと、この非対称は形が合う。

## 原典との突き合わせ

**支持する箇所。** 「位置」という語の使い方が支えになる。原典は関係を、要素の性質ではなく配置として語る。圏論もそうだ。中身は問わず、関係だけを見る。**語っている水準が揃っている。**

主体と対象を区別し続けることも、よく噛み合う。対等でありながら同じではない、という扱いは、随伴の左右の非対称と形が一致する。

**緊張する箇所は三つある。**

一つ目。**圏に当たるものを特定できていない。** 随伴は二つの圏のあいだの関係だ。切り上げなら、実数の世界と整数の世界。では原典の側で、何がその「世界」なのか。本稿はそれを言えていない。**ここが言えない限り、比喩の域は出られない。**

二つ目。**「似ている」の扱い**。原典は、似ていることを対象の資格にする。ところが数学では「似ている」は一種類ではない。完全に重なる「同型」なのか、構造だけが一致する「同値」なのかで、意味が大きく変わる。原典の相似がどちらなのかは、書かれていない。

三つ目。**一意性の強さ**。随伴の一意性は強い主張だ。原典がそこまで言っているかは、正直わからない。アダムは取り替えのきかない個人だったのか。それとも、条件を満たす誰かであればよかったのか。原典からは、どちらとも読める。

## この仮説が言っていないこと

**愛が数学的構造だとは言っていない。** 借りたのは、対応が条件から定まりうる、という形だけだ。

**人間が神の関数だとは言っていない。** 随伴は二つの側の関係であって、一方を他方の写しにするものではない。むしろ、両側がそれぞれ独立に存在することが前提になっている。

**一意性を証明したとは言っていない。** 言っているのは、一意性を語る枠がある、ということだけだ。原典の主体と対象が実際にその条件を満たすと示したわけではない。

**これが唯一の読み方だとは言っていない。** `比喩` と宣言しているのは、圏が特定できていないからだ。特定できれば、格上げの余地はある。

## 反証条件

**第一。** 原典において主体と対象の組が任意で、誰と誰が組んでも同じように授受作用が成り立つとされるなら、この仮説は成立しない。一意性が消えるからだ。

**第二。** 四位基台の中心が構造を決める役割を持たず、ただの目印にすぎないとされるなら、条件との対応は成立しない。導出の第五段が折れる。

**第三。** 主体と対象の関係が完全に対称で、二つの側を区別する必要が無いとされるなら、随伴という非対称な対応は当たらない。第六段が成立しない。

## 開かれた問い

**随伴は一意性を保証する。では原典において、ある主体に対する対象は一つなのか。** 神にとってのアダムは、取り替えのきかない個人だったのか。それとも、条件を満たす誰かでよかったのか。

**前者なら、堕落は、代わりのきかないものの喪失になる。** [[irreversibility]] で扱った悲しみの深さが、ここから説明できるかもしれない。

随伴は、二つの世界のあいだの関係だ。**主体と対象は、同じ世界の住人なのか。それとも別の世界に属しているのか。** 神と人間を同じ世界に置くなら、随伴にはならない。別の世界に置くなら、その二つが何なのかを言わねばならない。

「似ている」とは、同型のことなのか、同値のことなのか。同型なら完全に重なる。同値なら構造だけが一致する。[[mutual-information]] では、似ていることが情報量を減らすという逆向きの緊張に当たった。**同値として読めば、その緊張は解けるかもしれない。**

随伴には向きがある。左と右は入れ替えられない。**愛する側と愛される側の非対称は、これに当たるのだろうか。** 原典は、神が先に愛すると言う。順序があるなら、向きがある。

向きのあるものを、対称な物差しで測ることはできない。
