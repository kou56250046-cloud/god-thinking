## 問い

QRコードは、少しくらい汚れていても読める。

端が破れていても、コーヒーの染みがついていても、スマホをかざせばちゃんとページが開く。これは魔法ではない。QRコードには、最初から「余分」が織り込まれている。本当に必要な情報より、わざと多めに書いてあるのだ。だから一部が失われても、残りから元の姿を割り出せる。

原典は、復帰は放置では起こらないとし、条件を立てることを要求する。

:::quote 0
蕩減復帰のために立てる条件のことを「蕩減条件」というのである
:::

ここで素朴な疑問が出る。**なぜ条件が要るのか。** 全能であれば、失われたものをそのまま元に戻せばいいのではないか。条件を課すのは厳しさなのか。それとも、別の理由があるのか。

情報の世界には、この問いへの明快な答えがある。**壊れたものを直すには、壊れる前に余分を持たせておくしかない。** 余分が無ければ、何が失われたのかを知る手がかりすら残らない。厳しさの問題ではない。可能かどうかの問題だ。

この形が蕩減と重なるかを見てみたい。

## 主張

**蕩減条件は、失われた分を埋めるために用意された「余分」として読める。**

情報をそのまま送ると、一部が壊れたときに元に戻せない。あらかじめ余分を足しておけば、壊れた箇所を突き止め、元の姿を取り戻せる。この余分を冗長性と呼ぶ。**冗長性のない情報は、原理的に訂正できない。**

原典が復帰に条件を求めるのは、罰としてではない。**元に戻すために必要な余分を確保するためだ。** それが本稿の読みだ。原典が蕩減条件の第一を「失った価値と同一のもの」とすることは、必要な余分の量が、失われた量で決まるという規則に対応する。

そしてここから、重い帰結が一つ出てくる。

**直せる量には、上限がある。** 余分を超える破損は、元に戻せない。

## 前提

**原典から置くもの。**

第一に、復帰には条件が要る（前掲の引用）。時間や恵みだけでは進まない。

第二に、その条件を立てるのは人間の側であり、神の側だけでは完結しない。

:::quote 1
神の創造目的は、人間がその責任分担を完遂することによってのみ完成できるようになっている
:::

第三に、原典は蕩減条件に三つの種類があるとし、その第一を、失った本然の位置と同一の価値をもって立てるものとしている（後編 緒論）。**量が量に対応する**という考え方が、ここにある。

**情報理論から置くもの。**

誤り訂正符号の考え方は単純だ。送りたい情報に、計算で導ける余分を付け加える。受け取った側は、余分と本体の辻褄が合うかを確かめる。合わなければ、どこが壊れたかを割り出して、元に戻す。

電話で名前の綴りを伝えるとき、「エー、ビー」ではなく「アメリカのA、ボストンのB」と言うのも、同じ工夫だ。音が一部聞き取れなくても、単語全体から正しい文字を割り出せる。

三つ押さえておく。

一つ目。**余分が無ければ、訂正は不可能だ。** これは技術の限界ではなく、原理の話だ。余分が無ければ、壊れた情報と正しい情報を見分ける手がかりが、そもそも存在しない。

二つ目。**直せる量には上限がある。** 入れた余分の大きさで決まる。QRコードも、半分以上が塗りつぶされれば読めない。上限を超えた破損は、直せないどころか、**間違ったものを正しいと判定してしまうことすらある。**

三つ目。**訂正と再送は、別の手段だ。** 直しきれないときは、元をもう一度送ってもらうしかない。「すみません、もう一度言ってください」。訂正は手元で完結するが、再送には送り手が関わる必要がある。

| 情報理論 | 原典 |
|---|---|
| 送りたい情報 | 創造本然の位置と状態 |
| 通信路での破損 | 堕落 |
| 冗長性 | 蕩減条件 |
| 符号距離と訂正能力 | 失った価値と同一の条件 |
| 訂正の上限 | 人間の側だけでは復帰しきれないこと |
| 再送 | メシヤの派遣、摂理の延長 |

## 導出

**一。** 壊れたものを元に戻すには、元が何だったかを知る手がかりが要る。手がかりが情報の内側に無ければ、外から持ってくるしかない。

**二。** 情報の内側に手がかりを置くのが、冗長性だ。**余分は無駄ではない。元に戻せる可能性そのものだ。**

**三。** 原典が復帰に条件を課すのは、この余分を立てる作業として読める。条件が無ければ戻れないのは、神が許さないからではない。**戻るための手がかりが、存在しないからだ。**

**四。** 量の対応もつく。符号では、直せる誤りの量は、余分の大きさで決まる。原典では、蕩減条件は失った価値と同一であることを求められる。**どちらも「失った分だけ要る」という形をしている。**

**五。** ここから、値切れないことが出てくる。[[transition-state]] では、蕩減を活性化エネルギーとして読み、峠の高さは越える側の都合では変わらないと述べた。情報の側からも、同じ結論が出る。**必要な余分は、誠意や事情では減らない。** 「気持ちはこもっているので」と言っても、汚れたQRコードは読めない。

**六。** そして、上限の話になる。余分を超える破損は直せない。原典が、人間の責任分担だけでは復帰が完成せず、外からメシヤが必要だとすることは、**手元の訂正では足りず、再送が要る状態**として読める。ここは、本稿が最も強く主張できるところだ。

## 原典との突き合わせ

**支持する箇所。** 蕩減条件が、量を持つ条件として定義されていることが大きい。ただの儀礼なら、量は要らない。原典は「失った本然の位置と状態と同一なる価値の条件」と、量で語る。**量で語られている以上、量の理論を当てる余地がある。**

摂理が延長されるという記述も噛み合う。訂正に失敗すれば、もう一度送り直すしかない。原典が同じ型の摂理を、人物を変えて繰り返すと述べることは、再送の繰り返しとして読める。

**緊張する箇所は二つある。**

一つ目は、**余分がいつ積まれたのか**だ。符号では、余分は送る前に入れる。QRコードの余分は、印刷する前に計算されている。壊れてから足すことはできない。ところが原典では、蕩減条件は堕落の後に立てられる。この順序は、本稿の枠と合わない。**壊れた後に余分を積めるのはなぜか。** それが説明できていない。

二つ目は、**誰が払うのか**だ。符号の余分は、送り手が用意する。原典では、蕩減条件を立てるのは人間の側、とりわけ摂理の中心人物だ。負担の所在が逆に見える。

## この仮説が言っていないこと

**救いが計算だとは言っていない。** 借りたのは、余分が無ければ元に戻せない、という構造だ。元に戻すことの中身を、符号の操作に置き換えてはいない。

**蕩減が軽いものだとは言っていない。** むしろ逆だ。値切れないことが、本稿の帰結である。

**人間が情報だとは言っていない。** 対応させたのは、失われたものを取り戻す過程の形だけだ。

**どんな破損も直せるとは言っていない。** 上限があることを、この仮説は重く見ている。上限があるからこそ、外からの関わりが要る、という話になる。

## 反証条件

**第一。** 原典において、復帰が失われた分と無関係な恵みだけで達成されるとされるなら、冗長性との対応は成立しない。その場合、量の対応が消える。

**第二。** 蕩減条件の大きさが、失った価値と無関係に決まるとされるなら、符号との対応が崩れる。導出の第四段が折れる。

**第三。** どれほど壊れても必ず元に戻せるとされるなら、訂正の上限という構造が当たらなくなる。第六段が成立しない。

**第四。** 原典において、復帰に要る条件の量が、立てる側の誠意や熱心さで減らせるとされるなら、この仮説は成立しない。余分は、事情で目減りしない量だからだ。導出の第五段が、その場合に折れる。

## 開かれた問い

**余分は、いつ積まれたのか。** 符号では、壊れる前に入れる。原典では、壊れた後に立てる。この食い違いは、二つの読み方を許す。

ひとつは、本稿の対応がここで破れている、という読み。もうひとつは、**創造の時点で、すでに余分が入っていた**という読みだ。後者を採ると、重い帰結が出てくる。神は、壊れることを見込んで造ったことになる。

直せる誤りには上限がある。**原罪は、その上限を超えていたのか。** 超えていたとすれば、復帰は訂正ではなく再送だ。人間の側の努力では、原理的に届かないことになる。原典が救い主を必要とする理由に、量の面から説明がつく。

誰が、余分の費用を払うのか。符号では送り手が払う。原典では、中心人物が払っているように見える。**払う側が入れ替わっているなら、それは何を意味するのか。**

最後に。元に戻された情報は、元の情報と同じものなのか。符号の上では同じだ。汚れたQRコードから読み取ったURLは、きれいなQRコードから読み取ったものと一文字も違わない。しかし、通ってきた道は違う。

[[irreversibility]] で立てた「復帰した世界は、堕落しなかった世界と同じか」という問いが、ここでも同じ形で現れる。**情報としては同じで、履歴としては違う。** この二つは、分けて考えるべきなのかもしれない。
