## 問い

文章を書いていて、段落をひとつ消してしまったとする。慌てずに「元に戻す」を押せば、消えた段落は帰ってくる。二回押せば、その前の操作も取り消される。

ただし、それができるのは履歴が残っている間だけだ。**保存して閉じてしまえば、履歴は消える。** 次に開いたときに「元に戻す」を押しても、何も起きない。今の文面しか残っていないからだ。

原典の復帰には、はっきりした規則がある。**失った道を、逆向きにたどれ。**

:::quote 0
これを知るためには、元来アダムが、どのような経路によって創造目的を成就し得なくなったのであるかということを、まず知らなければならない。なぜなら蕩減条件は、本然の位置と状態を失うようになった経路と反対の経路をたどって立てなければならないからである
:::

素朴に考えると、回りくどい。全能の神なら、世界をまるごと堕落の前の状態に書き戻せばよさそうに見える。なぜ、やり直しではなく、たどり直しなのか。

計算の理論には、この二つを厳密に区別する枠がある。**逆にできる計算**と、**逆にできない計算**の区別だ。

## 主張

**戻れる計算と戻れない計算の差は、情報を捨てたかどうかで決まる。** 捨てていなければ、経路を逆にたどって元に戻れる。捨ててしまえば、どうやっても戻れない。

原典が蕩減条件を「反対の経路」として規定することは、**復帰を、逆計算として組み立てた**形をしている。本稿はそう読む。

そうすると、「なぜ神は一括で初期化しなかったのか」という問いに、構造の側から一つ答えが出る。**初期化は、情報を捨てる操作だからだ。** 捨てられるものの中には、人間が自分で果たすはずだった部分も含まれる。

先に断っておく。本稿は `構造的対応` として出す。対応させるのは、操作が逆にできるかどうかという性質と、逆にするには履歴が要るという条件の二つだけだ。摂理を計算機の動作と同じものだとは言わない。

## 前提

**原典から置くもの。**

第一に、蕩減条件は「反対の経路」をたどって立てる（前掲の引用）。そしてその前に、**どんな経路で失ったのかを知らねばならない**とされる。経路の記録が、復帰の前提条件になっている。

第二に、この規則は個々の堕落性にも当てはめられる。

:::quote 1
その堕落性本性をもつようになった経路と反対の経路をたどることによって、蕩減条件を立てなければならなかったのである
:::

天使長がアダムを愛せなかったことから生じた性質は、天使長の立場にある者がアダムの立場にある者を愛することで脱ぐ。**一つひとつの操作に、それを打ち消す逆の操作が割り当てられている。**

第三に、中心人物が失敗すると、その人物が立てるはずだった条件に、それ以前の失敗の分が加わるとされる。蕩減は累積する。

**計算論から置くもの。**

一つ目は**ランダウアーの原理**（Landauer 1961）だ。「かつ」の演算を考えてほしい。出力が 0 だったとき、入力は (0,0) だったのか (0,1) だったのか (1,0) だったのか。出力からはわからない。**入力の情報が捨てられている。** こうした操作は論理的に逆にできない。そして情報を 1 ビット捨てるたびに、最低でも決まった量の熱が外へ出る。この下限は、2012 年に実験でも確かめられた（Bérut ら）。

二つ目は**可逆計算**（Bennett 1973）だ。どんな計算も、途中の履歴を残しながら進めれば、逆にたどれる形に作り直せる。Fredkin と Toffoli は、入力を一つも捨てない論理素子だけで計算が組めることを示した。

三つ目は、ベネットが示した手順だ。**前向きに計算し、答えを写し取り、それから同じ道を逆向きにたどって履歴を片づける。** 最後には、写した答えだけが残り、途中の散らかりは消さずに回収される。

| 可逆計算 | 原典（本稿の読み） |
|---|---|
| 履歴の記録 | 失った経路を「まず知る」こと |
| 逆計算 | 反対の経路をたどる蕩減条件 |
| 各操作の逆操作 | 各堕落性に割り当てられた、それを脱ぐ条件 |
| 初期化（消去） | 経路を問わない一括の書き戻し |
| 逆計算の後に残る答え | 復帰の後に残るもの |

## 導出

**一。** 堕落の後の状態だけを見ても、どの道を通ってそこに来たのかは一つに決まらない。「かつ」の出力が 0 であることから、入力が決まらないのと同じだ。**今の状態は、経路を忘れている。**

**二。** だから、逆向きにたどるには、状態とは別に経路の記録が要る。原典が「まず知らなければならない」と書くのは、この条件に当たる。**知らないままでは、どちらへ戻せばよいかがわからない。**

**三。** もう一つの道として、初期化がある。中身を問わず、すべてを決まった状態へ書き戻す操作だ。これは計算論でいう消去の典型で、逆にできない操作の代表でもある。初期化は速い。しかし、**書き戻される前にそこにあったものは、すべて失われる。**

**四。** 失われるものの中には、人間の側の履歴が含まれる。原典は、人間の責任分担を神が代わりに果たすことはない、とする。初期化は、人間が通った道も、これから果たすはずの部分も、神の側でまとめて上書きする操作になる。[[control-autonomy]] で見た、制御を手放すという設計と、初期化は正面からぶつかる。**逆計算なら、たどるのは人間自身だ。**

**五。** 逆計算には、もう一つ性質がある。**順序に縛られる。** 最後に行った操作から先に戻さなければ、前の操作は戻せない。重ねた皿を下から抜けないのと同じだ。原典の蕩減が、どの順に立ててもよいものではなく、摂理の型として順序を持って語られることと、この性質は形が合う。

**六。** 累積にも説明がつく。可逆計算では、前向きに一歩進むごとに、逆向きにたどる道も一歩延びる。失敗した試みも前向きの一歩に数えられる。**だから失敗のたびに、戻る道が長くなる。** 原典で、後の中心人物が前の人物の失敗の分まで条件を立てねばならないのは、この延びた道として読める。

## 原典との突き合わせ

**支持する箇所。** 何より、「反対の経路」という言い方そのものだ。原典は復帰を、到達点の指定ではなく、道筋の指定として語る。どこへ戻るかではなく、**どう戻るか**を定めている。これは逆計算の考え方にそのまま重なる。

経路を「まず知らなければならない」という前置きも支えになる。可逆計算で履歴が要るのと同じように、原典でも経路の記録が復帰の前提に置かれている。

**緊張する箇所は三つある。**

一つ目は、[[hysteresis]] との食い違いだ。あちらでは、戻る道は来た道と一致しないと読んだ。その記事の反証条件の第一は、「復帰が創造の逆順をたどるとされるなら」だった。本稿が引いた一節は、まさにその条件に近い。**二つの記事は、そのままでは両立しない。**

ただし、和解の余地はある。可逆計算で逆にたどるのは、通った**状態**の列だ。使う**操作**は前向きのものとは別で、足し算の逆は引き算になる。原典の例でも、憎んだ者は、同じ道を引き返すのではなく、愛して十字架を負うことで戻る。**通る場所は同じでも、使う道具は違う。** ヒステリシスが言っていたのは、道具の重さのほうだったのかもしれない。

二つ目は、**経路の記録が不完全なこと**だ。逆計算は、履歴が一か所でも欠ければ失敗する。人間の側に、堕落の経路の完全な記録があったとは考えにくい。原典は、その記録を摂理の歴史と啓示に委ねているように見えるが、そう明言してはいない。

三つ目は、**散逸の扱い**だ。ランダウアーの原理では、捨てた情報は熱として外に出て、二度と戻らない。堕落のときに何かが捨てられたのなら、逆計算でも取り戻せない部分が残ることになる。[[irreversibility]] で扱った神の悲しみが、この取り戻せない部分に当たるのかどうか。本稿では決めきれない。

## この仮説が言っていないこと

**摂理が計算だとは言っていない。** 借りたのは、逆にできる操作と、逆にできない操作の区別と、逆にするには履歴が要るという条件だけだ。

**神が初期化できなかったとは言っていない。** 全能性の限界を主張しているのではない。初期化を選ばない理由が、構造の側からも一つ説明できる、と言っているだけだ。

**蕩減の量をビットや熱で測れるとは言っていない。** ランダウアーの下限は物理量だが、本稿はそれを摂理に持ち込まない。対応させたのは、散逸するものは戻らないという形だけだ。

**逆計算をたどれば必ず復帰が成るとは言っていない。** たどるかどうかは人間の責任分担に残っている。道が決まっていることと、それを歩くことは別だ。

## 反証条件

**第一。** 原典において、蕩減条件が失った経路と無関係な任意の善行で代えられるとされるなら、この仮説は成立しない。経路をたどるという規定が消えれば、逆計算と対応させる根拠も消える。

**第二。** 復帰の完成が、堕落から後の歴史をすべて消し去る完全な初期化として描かれるなら、本稿の読みは逆になる。その場合、復帰は逆計算ではなく消去であり、導出の第三段と第四段が折れる。

**第三。** 「反対の経路」が内容の反転だけを意味し、どの順で立てても等しいとされるなら、順序に縛られるという逆計算の性質は当たらない。導出の第五段が成立せず、対応は半分に縮む。

## 開かれた問い

**逆計算は、最後に行った操作から先に戻す。では、復帰摂理は、堕落の最後の段から先に取り消しているのか。** 原典の堕落は、天使長とエバの関係から始まり、アダムとエバの関係で終わる。復帰の順が本当にその逆になっているかを確かめれば、この仮説は検査できる。

**履歴を保持しているのは誰か。** 人間の記憶か、摂理の歴史か、神の側か。人間が自分の堕落の経路を知らないまま、逆にたどることはできない。**記録を持つ者と、道をたどる者が別人なら、両者の間に何かが通っていなければならない。**

**失敗も履歴に加わるなら、蕩減の累積は、戻る道が延びた記録なのか。** もしそうなら、摂理の延長は罰ではなく、単に道の長さの問題になる。原典がそう読まれることを許すかどうかは、わからない。

**最後に。** 可逆計算は、ゆっくり行うほど失うものが少なく、理想的な極限では何も失わずに済む。急いで逆にたどれば、そのぶん散逸が出る。**復帰に長い時間がかかることは、何かを失わないための速さなのだろうか。**
