## 問い

自転車で峠道を越えたことがあるだろうか。

登りは地獄だ。ペダルは重く、足は痛み、何度も押して歩こうかと思う。三十分かけて、ようやく頂上に着く。そして下りは、ペダルをこがなくても五分で麓に着いてしまう。

同じ道なのに、行きと帰りで、かかるものがまるで違う。

原典の堕落は、一度の出来事として描かれる。ところが復帰には数千年を要し、その間に摂理は何度も延長される。この非対称は、どこから来るのか。

同じ二点のあいだを行き来するのに、片方は一瞬で、もう片方は途方もなく長い。化学では、これはごく標準的な光景だ。**坂を転がり落ちるのは自然に起こり、同じ坂を登るには外から力を加えなければならない。** 落ちる速さと登る労力は、そもそも同じ物差しで測るものではない。

この形が、神の摂理の記述と重なるかを見てみたい。重なるとすれば、なぜ堕落を防げなかったのかという問いと、なぜ復帰にこれほど時間がかかるのかという問いは、**同じ一つの構造の、表と裏**ということになる。

## 主張

**成長期間中の人間は、準安定な状態にある。** 完成という深い谷にはまだたどり着いておらず、浅いくぼみに留まっている。浅いくぼみは、外から小さく揺さぶられれば、別の谷へ落ちうる。

堕落は、この落下だ。落下には峠を越える必要がない。**ひとりでに進む。** だから一瞬で済む。

復帰は、逆向きの過程だ。落ちた谷から出るには峠を越えねばならず、**外から力を入れない限り起こらない。** そして原典において、その入れられるものが蕩減条件である。

つまり主張は、次の一文に縮む。

**蕩減条件は、活性化エネルギーに当たる。** この非対称は、神の怠慢でも人間の弱さでもない。準安定な系が一般に持っている性質だ。

## 前提

**原典から置くもの。**

第一に、成長期間は完成に至る途中で、人間はその期間を、責任分担を果たしながら通り抜けるとされる。通り抜けているあいだは、完成していない。

:::quote 0
万物は原理自体の主管性、または自律性により、成長期間（間接主管圏）を経過することによって完成する
:::

第二に、堕落には外からの誘因があった。原典は動機を明示する。天使長が、自分より人間が愛されることに減少感を覚えた、という記述だ。

:::quote 1
このような立場で愛の減少感を感ずるようになったルーシェルは、自分が天使世界において占めていた愛の位置と同一の位置を、人間世界に対してもそのまま保ちたいというところから、エバを誘惑するようになったのである
:::

第三に、復帰は放っておいては起こらない。条件を立てることが要る。

:::quote 2
蕩減復帰のために立てる条件のことを「蕩減条件」というのである
:::

**化学から置くもの。**

化学反応を、山と谷のある地形の上をボールが転がる様子として描く見方がある。谷は安定な状態、峠は反応の途中の状態、峠の高さが活性化エネルギーだ。

身近な例を挙げよう。紙は、燃えて灰と煙になったほうが化学的には安定だ。それなのに、机の上の本がひとりでに燃え出すことはない。マッチで火をつける、というきっかけが要る。そのきっかけが、峠を越えるための力だ。

ここで区別すべきことが二つある。

一つ目。**安定していることと、いちばん深いことは違う。** あるくぼみが局所的に安定であることと、それが最も深い谷であることは、別の話だ。局所的に安定なだけの状態を、準安定という。準安定な状態は、揺さぶられなければ長く留まる。けれど、ある大きさ以上の揺さぶりが加わると崩れる。

二つ目。**ひとりでに進むことと、速いことは違う。** ひとりでに進む過程とは、外から仕事を加えなくても進む過程のことで、速い過程のことではない。逆に、ひとりでには進まない過程は、外から何かを入れない限り、決して進まない。**待っても、起こらない。** ここが効いてくる。復帰がひとりでに進まないなら、時間をいくら与えても、自然には戻らない。

借りている範囲を表にしておく。これ以上は主張しない。

| 化学 | 原典 |
|---|---|
| 準安定状態 | 成長期間中の人間 |
| 大域的に深い谷 | 完成、直接主管圏 |
| 別の局所安定 | 堕落した状態、サタン主管下 |
| 擾乱 | 天使長からの誘惑 |
| 自発的な落下 | 堕落 |
| 活性化エネルギー | 蕩減条件 |
| 非自発的な過程 | 復帰摂理 |

## 導出

**一。** 成長期間中の人間は、完成していない。完成していない以上、最も深い谷にはいない。けれど崩れてもいないのだから、何らかのくぼみにはいる。これが準安定だ。

**二。** 準安定な状態は、ある大きさ以上の揺さぶりで、別の状態へ移る。原典は、その揺さぶりを特定している。愛の減少感を動機とする誘惑だ。**内側から自然に崩れたのではなく、外から加わった揺さぶりとして描かれている。** この点が、準安定という描き方とよく合う。

**三。** 落ちる側には、峠が要らない。要らないから、速い。堕落が一度の出来事として語られ、長い準備期間を持たないことは、この向きの過程がひとりでに進むことと矛盾しない。

**四。** 逆向きは、ひとりでには進まない。放っておいても戻らない。原典が「条件を立てなければならない」と繰り返すのは、まさにこのことの言い換えとして読める。何かを入れなければ、峠は越えられない。

**五。** だから蕩減条件は、峠を越えるために外から入れるものに当たる。ここから一つの帰結が出る。

**蕩減の重さは、罰ではない。** 罰なら、軽くすることに意味がある。けれど活性化エネルギーは値切れない。峠の高さは、越える側の都合では変わらない。自転車の登りがきついのは、坂があなたを罰しているからではない。

**六。** 摂理が延長されるという記述も、この枠で読める。峠の手前まで来て越えられなければ、ボールは元の谷へ転がり戻る。入れた力は失われ、また同じ高さを登り直すことになる。**中心人物が責任分担を果たせなかったとき摂理が延長される、という原典の記述は、失敗した反応が出発点に戻る様子と、形が重なる。**

## 原典との突き合わせ

**支持する箇所。** 蕩減条件という考え方そのものが、この仮説にとって最も強い支えだ。原典は復帰を、時間や恵みだけで進むものとして描かない。条件を立てること、つまり何かを入れることを求める。

さらに原典は、蕩減条件に三つの種類があるとし、その第一を、失った本然の位置と同一の価値をもって立てるものとしている（後編 緒論）。

失った価値と同じだけのものを立てる、という考え方は、**峠の高さが落ちた深さで決まる**という描き方と、形が合う。深く落ちたなら、それだけ高く登らねばならない。

**緊張する箇所は二つある。**

一つ目。**完成が本当に、いちばん深い谷なのか。** 原典は完成を最終目的として描く。けれど地形の比喩を厳密に取るなら、それがいちばん深い谷であることには証明が要る。ここは、比喩が原典より強く主張してしまう危険がある。本稿は「人間の側から見て、最も深い谷」という控えめな読みに留める。

二つ目。**ひとりでに進むことと、責任の関係**。化学では、ひとりでに進む過程に責任は伴わない。誰のせいでもない。ところが原典は、堕落を人間の責任として扱う。落下がひとりでに進んだという読みは、責任を薄める方向に働きうる。本稿はこの緊張を解消していない。準安定な状態に**留まり続けること**にも選択が要る、という読み方はありうる。ただ、原典がそう述べているわけではない。

## この仮説が言っていないこと

**堕落が物理的な出来事だとは言っていない。** 借りているのは、安定性と経路の形であって、実際の熱力学量ではない。蕩減の大きさをジュールで測れるとは主張しないし、測る意味があるとも思わない。

**罪を自然現象に置き換えてはいない。** ひとりでに進む過程だからといって、罪でなくなるわけではない。ここは前の節で書いたとおり、緊張として残している。

**神が非力だとは言っていない。** 峠があることは、峠を造った側の無能を意味しない。むしろ峠があるからこそ、完成した状態は安定していられる。峠の無い谷は、谷ではない。

**復帰が化学反応と同じ速さの法則に従うとは言っていない。** 反応の速さは温度や濃度で決まるが、摂理にそれに当たるものがあるとは主張しない。**対応させたのは、行きと帰りの非対称と、峠があることだけだ。**

## 反証条件

**第一。** 原典において、復帰がひとりでに進むもの、つまり条件を立てずに時間の経過だけで達成されるものとされるなら、この仮説は成立しない。蕩減条件という考え方そのものがこの反証を防いでいるが、別の文献が別の説明を与える可能性は残る。

**第二。** 堕落に外からの誘因が要らず、人間の内側だけで完結する出来事だとされるなら、準安定という描き方は成立しない。内側から自然に崩れるなら、それは準安定ではなく、不安定だ。

**第三。** 蕩減条件が失われた価値の補填ではなく、ただの儀礼的な手続きだとされるなら、活性化エネルギーとの対応は成立しない。大きさが意味を持たなくなるからだ。

**第四。** 成長期間中の人間が、完成体と同じ安定性を持つとされるなら、前提そのものが崩れる。その場合、堕落には別の説明が要る。

## 開かれた問い

峠の高さは、何で決まるのか。原典は蕩減条件に三つの種類があるとするが、どの場合にどれだけの高さが要るのかを決めているものが何なのかは、本稿の枠からは見えない。落ちた深さだけで決まるのか。それとも、落ち方によるのか。

**メシヤは、触媒なのか。それとも、外から入れられる力の源なのか。** これは思いのほか大きな分かれ道だ。触媒は峠を低くするが、行き先そのものは変えない。峠にトンネルを掘ってもらうようなものだ。トンネルがあっても、歩くのは自分の足である。一方、力の源なら、峠を越える力そのものが外から来る。車に乗せてもらうようなものだ。

原典の責任分担の考え方は、前者に近く見える。けれど救いという言葉は、後者を思わせる。ここは [[computational-irreducibility]] で扱った責任分担の問題と、地続きになっている。

最後に。堕落がひとりでに進んだのだとすれば、それは誰の責任にも帰せないのか。ひとりでに進むことと責任は、両立するのか。

この問いは、化学の側には存在しない。**借りてきた枠に無い問いが、借りた先で生まれている。** 対応が浅いからなのか。それとも枠を超えた何かがあるからなのか。まだ決められない。
