## 問い

堕落は一度の出来事として描かれる。ところが復帰には数千年を要し、しかもその間に摂理は何度も延長される。この非対称はどこから来るのか。

同じ二点の間を往復するのに、行きは一瞬で帰りは途方もなく長い。そういう事態は日常には珍しいが、化学では標準的な光景である。**坂を転がり落ちるのは自然に起こり、同じ坂を登るには外から力を加えなければならない。** 落ちる速さと登る労力は、そもそも同じ尺度で測るものではない。

この形が神の摂理の記述と重なるのかどうかを見る。重なるとすれば、なぜ堕落を防げなかったのかという問いと、なぜ復帰にこれほど時間がかかるのかという問いは、**同じ一つの構造の裏表**ということになる。

## 主張

**成長期間中の人間は準安定状態にある。** 完成という深い谷にはまだ達しておらず、浅い窪みに留まっている。浅い窪みは、外から小さな揺さぶりが加われば別の谷へ落ちうる。

堕落はこの落下である。落下には障壁を越える必要がなく、**自発的に進む。** だから一瞬で済む。

復帰は逆向きの過程である。落ちた谷から出るには障壁を越えねばならず、**外からエネルギーを入れない限り起こらない。** そして原典において、その入れられるものが蕩減条件である。

つまり主張は次の一文に縮む。**蕩減条件は活性化エネルギーに対応する。** 非対称は神の怠慢でも人間の弱さでもなく、準安定な系が持つ一般的な性質である。

## 前提

**原典から置くもの。**

第一に、成長期間は完成に至る途中であり、人間はその期間を責任分担を果たしながら通過するとされる。通過中は完成していない。

:::quote 0
万物は原理自体の主管性、または自律性により、成長期間（間接主管圏）を経過することによって完成する
:::

第二に、堕落には外的な誘因があった。原典は動機を明示する。天使長が、自分より人間が愛されることに減少感を覚えたという記述である。

:::quote 1
このような立場で愛の減少感を感ずるようになったルーシェルは、自分が天使世界において占めていた愛の位置と同一の位置を、人間世界に対してもそのまま保ちたいというところから、エバを誘惑するようになったのである
:::

第三に、復帰は放置では起こらない。条件を立てることが要る。

:::quote 2
蕩減復帰のために立てる条件のことを「蕩減条件」というのである
:::

**化学から置くもの。**

反応をポテンシャルエネルギー面の上の運動として描く見方がある。谷は安定な状態、峠は遷移状態、峠の高さが活性化エネルギーである。ここで区別すべきことが二つある。

一つ目は、**安定性と深さの違い**である。ある窪みが局所的に安定であることと、それが最も深い谷であることは別である。局所的に安定なだけの状態を準安定という。準安定状態は、揺さぶられなければ長く留まるが、ある大きさ以上の擾乱が加わると崩れる。

二つ目は、**自発性と速さの違い**である。自発的な過程とは、外から仕事を加えなくても進む過程のことであって、速い過程のことではない。逆に非自発的な過程は、外から何かを入れない限り決して進まない。**待っても起こらない。** ここが効く。復帰が自発的でないなら、時間をいくら与えても自然には戻らない。

対応を表にしておく。借りているのはこの範囲だけで、これ以上は主張しない。

| 化学 | 原典 |
|---|---|
| 準安定状態 | 成長期間中の人間 |
| 大域的に深い谷 | 完成、直接主管圏 |
| 別の局所安定 | 堕落した状態、サタン主管下 |
| 擾乱 | 天使長からの誘惑 |
| 自発的な落下 | 堕落 |
| 活性化エネルギー | 蕩減条件 |
| 非自発的な過程 | 復帰摂理 |

## 導出

**一。** 成長期間中の人間は完成していない。完成していない以上、最も深い谷にはいない。しかし崩壊もしていないのだから、何らかの窪みにはいる。これが準安定である。

**二。** 準安定な状態は、ある大きさ以上の擾乱で別の状態へ移る。原典はその擾乱を特定している。愛の減少感を動機とする誘惑である。**内発的な崩壊ではなく、外から加わった揺さぶりとして描かれている**点が、準安定という描像とよく合う。

**三。** 落下の側には障壁が要らない。要らないから速い。堕落が一度の出来事として語られ、長い準備期間を持たないことは、この向きの過程が自発的であることと整合する。

**四。** 逆向きは自発的でない。放置しても戻らない。原典が「条件を立てなければならない」と繰り返すのは、まさにこの非自発性の言い換えとして読める。何かを入れなければ峠を越えない。

**五。** よって蕩減条件は、峠を越えるために外から供給されるものに対応する。ここから一つ帰結が出る。**蕩減の重さは罰ではない。** 罰なら軽くすることに意味があるが、活性化エネルギーは値切れない。峠の高さは、越える側の都合では変わらない。

**六。** 摂理が延長されるという記述も、この枠で読める。峠の手前まで来て越えられなければ、系は元の谷へ落ち戻る。投入されたエネルギーは失われ、また同じ高さを登り直すことになる。**中心人物が責任分担を果たせなかったときに摂理が延長される、という原典の記述は、失敗した反応が出発点に戻る様子と形が重なる。**

## 原典との突き合わせ

**支持する箇所。** 蕩減条件という概念そのものが、この仮説にとって最も強い支えである。原典は復帰を、時間や恩寵だけで進むものとして描かない。条件を立てること、すなわち何かを投入することを要求する。

さらに原典は、蕩減条件に三つの種類があるとし、その第一を、失った本然の位置と同一の価値をもって立てるものとしている（後編 緒論）。

失った価値と同じだけのものを立てる、という考え方は、**峠の高さが落差によって決まる**という描像と形が合う。深く落ちたなら、それだけ高く登らねばならない。

**緊張する箇所が二つある。**

一つ目は、**完成が本当に大域的な最小なのか**という点である。原典は完成を最終目的として描くが、ポテンシャル面の比喩を厳密に取るなら、大域最小であることは証明を要する。ここは比喩が原典より強く主張してしまう危険がある。本稿は「人間の側から見て最も深い谷」という弱い読みに留める。

二つ目は、**自発性と責任の関係**である。化学において自発的な過程には責任が伴わない。誰のせいでもない。ところが原典は堕落を人間の責任として扱う。落下が自発的だという読みは、責任を薄める方向に働きうる。本稿はこの緊張を解消していない。準安定な状態に**留まり続けること**にも選択が要る、という読み方はありうるが、原典がそう述べているわけではない。

## この仮説が言っていないこと

**堕落が物理的な出来事だとは言っていない。** 借りているのは安定性と経路の形であって、実際の熱力学量ではない。蕩減の大きさをジュールで測れるとは主張しないし、測る意味があるとも思わない。

**罪を自然現象に還元していない。** 自発的な過程だからといって、罪でなくなるわけではない。ここは前節に書いたとおり、緊張として残している。

**神が非力だとは言っていない。** 峠が存在することは、峠を作った側の無能を意味しない。むしろ障壁があるからこそ、完成した状態は安定でいられる。障壁の無い谷は谷ではない。

**復帰が化学反応と同じ速度論に従うとは言っていない。** 反応速度は温度や濃度で決まるが、摂理にそれに当たるものがあるとは主張しない。**対応させたのは、自発性の非対称と、障壁の存在だけである。**

## 反証条件

**第一。** 原典において復帰が自発的に進むもの、すなわち条件を立てずに時間の経過だけで達成されるものとされるならば、この仮説は成立しない。蕩減条件の概念そのものが反証を防いでいるが、別の文献が別の説明を与える可能性は残る。

**第二。** 堕落に外的な誘因が不要であり、人間の内部だけで完結する出来事だとされるならば、準安定という描像は成立しない。内部から自然に崩れるなら、それは準安定ではなく不安定である。

**第三。** 蕩減条件が失われた価値の補填ではなく、単なる儀礼的な手続きであるとされるならば、活性化エネルギーとの対応は成立しない。値の大小が意味を持たなくなるからである。

**第四。** 成長期間中の人間が完成体と同じ安定性を持つとされるならば、前提そのものが崩れる。その場合、堕落は説明を別に要する。

## 開かれた問い

障壁の高さは何で決まるのか。原典は蕩減条件に三つの種類があるとするが、どの場合にどの高さが要るのかを決めているものが何なのかは、本稿の枠では見えない。落差だけで決まるのか、それとも落ち方によるのか。

**メシヤは触媒なのか、それとも外部から注入されるエネルギー源なのか。** これは思いのほか大きな分かれ道である。触媒は峠を低くするが、系の行き先そのものは変えない。つまり触媒があっても、越えるのは人間の側である。一方エネルギー源なら、越える力そのものが外から来る。原典の責任分担の考え方は前者に近く見えるが、救いという語は後者を思わせる。ここは [[computational-irreducibility]] で扱った責任分担の問題と地続きである。

堕落が自発的だったとすれば、それは誰の責任にも帰せないのか。自発性と責任は両立するのか。この問いは化学の側には存在しない。**借りてきた枠に無い問いが、借りた先で生まれている**ということであり、対応が浅いのか、それとも枠を超えた何かがあるのかは、まだ決められない。
